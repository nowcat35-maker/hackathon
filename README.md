# UniFit-S 🎓

## 1. 프로젝트 소개

UniFit-S는 대학생에게 필요한 장학금, 대외활동,
공모전 정보를 한곳에서 확인하고 개인의 관심사와
조건에 맞는 정보를 추천하는 맞춤형 웹서비스입니다.

정보 탐색부터 지원 자격 확인, 마감 일정 관리까지
대학생의 정보 활용 과정을 편리하게 지원합니다.

## 2. 주요 기능

- 장학금, 대외활동, 공모전 정보 통합 제공
- 사용자 관심사 기반 맞춤형 추천
- AI 임베딩 유사도 기반 적합도 표시
- 지원 자격 조건 진단 및 추천 이유 제공
- 모집 마감일 및 D-Day 확인
- 관심 공고 및 지원 현황 관리
- 캘린더 일정 관리
- 사용자 프로필 및 관심 키워드 설정

## 3. 개발 환경 및 기술

- Frontend: HTML, CSS, JavaScript
- Data: Excel 기반 공고 데이터
- AI: 임베딩 유사도 기반 추천 기능
- Development Tool: Visual Studio Code, Google Colab

## 4. 프로젝트 실행 방법

1. GitHub 저장소를 다운로드합니다.
2. 압축을 해제합니다.
3. 프로젝트 폴더를 엽니다.
4. 웹 브라우저에서 실행합니다.

## 5. 프로젝트 구조

프로젝트의 주요 HTML 파일과
기능별 페이지 및 리소스로 구성되어 있습니다.

## 6. 기대 효과

- 대학생의 정보 탐색 시간 절약
- 개인별 관심사에 적합한 정보 제공
- 지원 자격 및 마감 일정 관리 편의성 향상

## 7. 유의사항

추천 및 지원 자격 진단 결과는 참고용이며,
실제 지원 전에는 반드시 해당 기관의 공식 공고를
확인해야 합니다.
